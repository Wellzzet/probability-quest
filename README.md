# 🛡️ Probability Quest

Игра-курс по теории вероятностей на Python (Streamlit). Темы взяты из пробного теста по теории вероятностей.

**Языки:** русский, английский, казахский — переключатель 🇷🇺 RU / 🇬🇧 EN / 🇰🇿 KZ вверху боковой панели (и на экране создания персонажа). Переводятся интерфейс, уроки, задачи с решениями, калькуляторы, Босс и проектная работа.

## Как устроено
- **8 тем:** классическая вероятность → комбинаторика → операции над событиями → условная вероятность →
  независимость → полная вероятность → Байес → дискретная случайная величина.
- В каждой теме есть **урок** (теория, формулы, словарь RU/EN/KZ, разборы задач теста) и **испытание**
  (5 случайных задач, нужно ≥ 4 верных).
- **Калькуляторы** по каждой теме показывают пошаговые решения. Ввод: `3/8`, `0.375` или `37.5%`.
- **Экономика:** за испытание дают 🪙 и ⭐; на монеты в Лавке покупается следующая тема.
- **Кузница:** каждая пройденная тема выковывает часть доспехов.
- **Финал:** Босс задаёт 10 задач из теста. После победы персонаж получает полные доспехи и
  **проектную работу** «Вероятностная лаборатория».
- **Сохранение:** через JSON-файл в боковой панели.

## Запуск локально
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Публикация (как Almaty-flats)
1. Создайте репозиторий на GitHub и загрузите туда эту папку.
2. На https://share.streamlit.io → **Create app** → выберите репозиторий, ветку `main`, файл `app.py`.
3. Нажмите **Deploy**.

## Структура
```
app.py                 — страницы и навигация
game/content.py        — темы, словарь терминов (RU/EN/KZ), доспехи
game/lessons_*.py      — тексты уроков: ru, en, kk
game/i18n.py           — переключение языков
game/quiz.py           — генераторы случайных задач
game/calculators.py    — калькуляторы
game/boss.py           — задачи Босса (из теста)
game/project.py        — финальная проектная работа
game/avatar.py         — персонаж и доспехи (SVG)
game/state.py          — монеты, опыт, сохранение
```
